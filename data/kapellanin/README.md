# Данные с сайта «Капелланин» (kapellanin.ru)

`students.json` — 34 ученика Т.И. Хитровой по классу дирижирования, собраны 2026-09-14 со страницы
https://kapellanin.ru/names/?id=51 и персональных страниц каждого ученика (`/idNNN`).

Структура: `meta` (источник, дата, кем собрано, описание полей) и `people[]`:
- `kapellanin_id`, `source_url`, `full_name`, `short_name`, `gender`, `birth_date`, `death_date`;
- `choir_school_start/end/honors/status`, `conservatory_end`, `assistantship_end` — разобраны из текста;
- `teachers[]` — педагоги по классам (с id на Капелланине);
- `bio_lines[]` — остальные строки биографии как есть;
- `events[]` — участие в событиях (дата, название, ссылка);
- `site_materials[]`, `references[]` — материалы и библиография на Капелланине;
- `photos[]` — только ссылки на миниатюры и подписи (2079 групповых фото). Файлы НЕ скачивались;
- `site_record` — поля 1:1 под таблицу `public.people` сайта памяти, `source` уже содержит ссылку на Капелланин.

Правила использования: при публикации на сайте памяти у каждой карточки указывать `source_url`;
фотографии использовать только с разрешения сайта «Капелланин». Данные в `people` сайта уже частично
содержат этих людей (сид из архивного списка) — при импорте сопоставлять по `full_name`, не дублировать.
