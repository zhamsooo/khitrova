# Задание v3: редизайн сайта под Material Design 3

Техзадание для ИИ-модели в репозитории. Прочитай целиком, затем `docs/design-rules.md` (новые правила, M3) и открой в браузере `docs/mock-people-m3.html` — это эталон, к которому должен прийти весь сайт. Контекст архитектуры и журнал — `docs/project-notes.md`. Бриф v2 (`docs/brief-wiki-v2.md`) выполнен полностью, функционал оттуда сохраняется без изменений: меняется только внешний вид и вёрстка. Выполняй **только названную задачу**.

## Что решил владелец (не обсуждается)
- Весь сайт переводится на Material Design 3, палитра «baseline» (фиолетовая, seed #6750A4), шрифт Roboto, иконки Material Symbols Rounded.
- Единый контейнер 1040px на всех страницах, одна левая линия для шапки, вкладок, контента и таймлайна.
- Карточки в сетках одинаковой высоты и ширины, длинный текст обрезается; метаданные скрыты и показываются по hover.
- Одна кнопка добавления — FAB «Добавить». На телефоне навигация внизу (navigation bar), бургер удаляется.
- Откат: git-тег `v1-design`. Ничего не бояться, но и функционал (Supabase-вызовы, модерация, ревизии, редактор статей) не ломать.

## Метод: волнами, не страницами
Не «доделать одну страницу идеально, потом следующую», а «все страницы черново, потом все на шаг лучше». После каждой задачи сайт должен работать на всех страницах, пусть и не идеально.

## Задача R1. Каркас: токены, шрифты, шапка, FAB (волна 1 по всем страницам)
1. `style.css` переписать с нуля по `design-rules.md`: `:root` с токенами цвета, шкалой `--t-*`, радиусами, контейнером; reset; классы компонентов (`.appbar`, `.tabs`, `.tab`, `.navbar` для телефона, `.fab`, `.btn.filled/.tonal/.outl/.text`, `.chip`, `.search`, `.card`, `.field`, `.dialog`, `.snackbar`, `.badge`, `.sym`, `.iconbtn`). CSS из макета `docs/mock-people-m3.html` можно брать как основу — он уже написан в этих токенах.
2. На всех страницах (`index`, `people`, `person`, `nasledie`, `moderation`) заменить подключение шрифтов: убрать PT Serif / PT Sans Narrow / Cormorant, добавить Roboto + Material Symbols Rounded одной ссылкой из `design-rules.md` п.2.
3. `app.js` → `initHeader`: рендерить top app bar + primary tabs (десктоп) и navigation bar (телефон) как в макете; FAB «Добавить» вместо кнопки в шапке; иконка модерации с бейджем-счётчиком; аватар/«Войти». Старые «+ Добавить человека» (`people.html`), «+ Написать» (`nasledie.html`), бургер и `.site-nav .links` — удалить.
4. Контейнер: обернуть контент каждой страницы в один `.page` (max-width 1040, gutter 24/16). На главной — тоже, таймлайн внутри контейнера (детали выравнивания — в R4, здесь достаточно, чтобы шапка и таймлайн начинались с одной линии).
5. Старые `<style>` внутри страниц пока не переписывать полностью — только убрать то, что конфликтует (шрифты, старые цвета `--ink/--paper/--accent` заменить на токены M3 через алиасы в `:root`, чтобы страницы не развалились до R2–R3).
Критерий: все пять страниц открываются без ошибок в консоли, шапка/вкладки/FAB одинаковы везде, шрифт Roboto везде, левая линия совпадает на всех страницах на 1280px.

## Задача R2. Карточки, сетки, списки (волна 1)
1. `people.html`: карточки ровно как в макете: `--surface-low`, высота 172, 3/2/1 колонки, имя в одну строку, описание clamp 2, полоска метаданных по hover с ⓘ (поповер из задачи 4 брифа v2 остаётся), бейдж статуса только у неподтверждённых. Группировка по десятилетиям — заголовок `label-large` + счётчик. Чипы-фильтры и search bar — из макета.
2. `nasledie.html`: карточки материалов по тому же шаблону (заголовок, тип/автор/год в `body-medium`, обложка если есть — сверху 16:9 внутри карточки, метаданные по hover). Две секции (Т.И. / коллеги) — заголовки `headline-small`; пустое состояние — M3-карточка с иконкой `menu_book` и tonal-кнопкой.
3. `person.html`: двухколоночный layout в контейнере (основная колонка + боковая 320px). Шапка человека: аватар 80px, имя `display-small`, подпись `body-medium`; вехи учёбы — M3 list items с иконкой `school`; «Учились вместе» — list с аватарами-инициалами; кнопки «Предложить правку» (tonal) и ⓘ (iconbtn). Хлебные крошки `label-large` с `chevron_right`.
4. `moderation.html`: карточки очереди — `--surface-low`, радиус 12; кнопки «Подтвердить/Применить» filled, «Отклонить» outlined с `--error`, заметка модератора — outlined text field; таблица диффа — M3 data table (строки 52px, `--outline-variant` разделители, горизонтальный скролл на телефоне).
Критерий: на 1280 и 375 карточки одной высоты, ничего не переполняется, метаданные не видны в покое.

## Задача R3. Формы, диалоги, поповеры, уведомления (волна 1)
1. Единый диалог добавления (три таба): basic dialog 720px, радиус 28, `--surface-high`; табы — M3 secondary tabs; поля — outlined text field с плавающим label и supporting text; ошибки — `--error` под полем; кнопки внизу справа: text «Отмена» + filled «Отправить». На < 600px — full-screen dialog с app bar (`close`, заголовок, filled-кнопка в баре).
2. Те же правила для: диалога входа по коду, «Предложить правку» (человек, событие, статья), профиля.
3. Тосты → snackbar. Подсказки → tooltip (plain, `--inverse-surface`).
4. Поповер метаданных → карточка `--surface-high`, список истории — M3 list items (иконка `history`, две строки).
5. Редактор статей (Editor.js): не переписывать, только обернуть в контейнер и привести панель метаданных статьи к outlined-полям и chips.
Критерий: все формы сайта выглядят одной семьёй; на 375px любая форма полноэкранная, кнопка действия видна без скролла.

## Задача R4. Главная и TimelineJS (волна 1)
1. `index.html`: таймлайн внутри контейнера 1040; контент слайда (`.tl-slide-content`, `.tl-text`) выровнен по левой линии контейнера — та самая линия, по которой владелец выравнивал меню по фото. Шапка сайта над таймлайном — та же, что везде.
2. Переопределения TimelineJS: шрифты Roboto; цвета из токенов (`.tl-headline` `--on-surface`, `.tl-timenav` фон `--surface-low`, маркеры и активный элемент `--primary`, линии `--outline-variant`). Убрать все старые tl-переопределения под PT/Cormorant.
3. Попап события (`#evTip`) — M3-карточка `--surface-high` с бейджем статуса, кнопками tonal «Предложить правку» и iconbtn ⓘ; подсказка навигации по стрелкам — tooltip.
4. Заставка (первый слайд с портретом и должностью) — оставить, только шрифты/цвета из токенов.
Критерий: главная и «Люди» открыты рядом — шапка, вкладки и левая кромка контента совпадают пиксель в пиксель.

## Правила для исполнителя
- Функционал не трогать: все вызовы `sb.from(...)`, `sb.rpc(...)`, логика модерации и ревизий, Editor.js, TimelineJS-данные остаются как есть. Меняется разметка, классы, CSS, иконки, тексты кнопок.
- Не добавлять сборщики, фреймворки, npm. Material Web Components не подключать — всё на обычном CSS по токенам.
- Каждая задача — отдельная сессия и отдельный коммит с сообщением по-русски («R1: каркас M3 — токены, Roboto, app bar, FAB»). Перед началом — `git pull`; перед коммитом — `git status`, только свои файлы.
- После каждой задачи — 3–5 строк в «Журнал» `docs/project-notes.md` с датой.
- Сайт после каждой задачи должен работать на всех страницах (автодеплой публикует сразу). Если задача не влезает в сессию — закоммитить рабочее состояние, а не половину.
- Если что-то в задании противоречит коду или невозможно — остановиться и написать вопрос в отчёте, не изобретать обход.
