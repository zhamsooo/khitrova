# Дизайн-правила: Material Design 3 (решение владельца 2026-09-14)

Сайт целиком переводится на Material Design 3 (m3.material.io). Это не «вдохновение», а система: компоненты, токены цвета, типографика и формы берутся из M3 буквально. Самодельных стилей «по вкусу» не заводить. Эталон вёрстки и плотности — `docs/mock-people-m3.html` (страница «Люди»): открой его в браузере перед работой и делай так же по структуре; цвета в нём устарели (фиолетовые палитры), токены брать из §1 ниже.

Старые правила (Cormorant/PT Serif, бронза) — в `docs/design-rules-v1-archive.md`, они отменены. Откат всего дизайна: git-тег `v1-design`. Откат к фиолетовой палитре M3: git-тег `v2-m3-purple`.

## 1. Цвет — схема M3 Prussian & Denim / Deep Blue (решение владельца 2026-09-14)
Все цвета только через переменные в `:root` в `style.css`. Ни одного hex в компонентах.

Палитра: Ink Black `#0D1B2A`, Prussian Blue `#1B263B`, Dusk Blue `#415A77`, Dusty Denim `#778DA9`, Alabaster Grey `#E0E1DD`.

```
--primary:#1B263B;  --on-primary:#FFFFFF;  --primary-container:#DBE4EE;  --on-primary-container:#0D1B2A;
--secondary:#415A77; --secondary-container:#E0E1DD; --on-secondary-container:#0D1B2A;
--tertiary:#778DA9; --tertiary-container:#E8ECEF; --on-tertiary-container:#1B263B;
--error:#BA1A1A; --on-error:#FFFFFF; --error-container:#FFDAD6; --on-error-container:#410002;
--surface:#FFFFFF; --surface-low:#F4F6F8; --surface-mid:#ECEFF2; --surface-high:#E5E9EC; --surface-highest:#E0E1DD;
--on-surface:#0D1B2A; --on-surface-variant:#415A77; --outline:#778DA9; --outline-variant:#D0D7DE;
--inverse-surface:#0D1B2A; --inverse-on-surface:#E0E1DD; --inverse-primary:#778DA9;
```
Роли (кому что):
- Фон страницы `--surface` (#FFFFFF); карточки и панели `--surface-low` (#F4F6F8, покой) / `--surface-mid` (#ECEFF2, hover) / `--surface-high` (#E5E9EC, поля поиска, выезжающая полоска метаданных); диалоги `--surface-high`; высший уровень поверхностей `--surface-highest` (#E0E1DD).
- Основной текст `--on-surface` (Ink Black `#0D1B2A`); вторичный и подписи `--on-surface-variant` (Dusk Blue `#415A77`); рамки `--outline` (Dusty Denim `#778DA9`: поля, чипы, outlined-кнопки) и `--outline-variant` (`#D0D7DE`, разделители).
- Главное действие `--primary` (Prussian Blue `#1B263B`: filled-кнопка, активная вкладка с 2px линией, индикатор, выбранный chip); tonal-кнопки и активные чипы в контейнерах `--secondary-container` (Alabaster Grey `#E0E1DD`).
- Статусы: подтверждено `--primary-container`/`--on-primary-container`; на проверке `--tertiary-container`/`--on-tertiary-container` с иконкой `schedule`; отклонено `--error-container`. Отдельных «зелёных/жёлтых» не заводить.
- State layers: hover = `--on-surface` 8 %, focus/pressed = 12 % (можно через `color-mix(in srgb, var(--on-surface) 8%, transparent)` поверх фона).
- Тёмная тема — не в этом объёме; но красить фон и текст только токенами, чтобы её можно было добавить одним блоком.

## 2. Типографика — Roboto
Подключение на каждой странице: `https://fonts.googleapis.com/css2?family=Roboto:ital,wght@0,400;0,500;0,700;1,400&family=Material+Symbols+Rounded:opsz,wght,FILL,GRAD@20..48,400,0..1,0&display=swap`. Fallback: `Roboto, -apple-system, "Segoe UI", sans-serif`. PT Serif, PT Sans Narrow, Cormorant — удалить отовсюду, включая переопределения TimelineJS.

Шкала M3 (размер/интерлиньяж/вес/трекинг), переменные `--t-*`:
- `display-small` 36/44/400/0 — заголовок страницы (H1: «Люди», «Наследие», имя человека на его странице).
- `headline-small` 24/32/400/0 — заголовки секций и диалогов.
- `title-large` 22/28/400/0 — заголовок в top app bar.
- `title-medium` 16/24/500/.15 — имена на карточках, заголовки списков.
- `body-large` 16/24/400/.5 — основной текст, поля ввода, лид. Текст статей — `body-large`, ширина колонки ≤ 68ch.
- `body-medium` 14/20/400/.25 — описания на карточках, вторичный текст.
- `label-large` 14/20/500/.1 — кнопки, чипы, вкладки.
- `label-medium` 12/16/500/.5 — метаданные, подписи под полями, бейджи. Нижняя граница; меньше не бывает.

Иконки — только `Material Symbols Rounded` (класс `.sym`, ligature-имя внутри: `search`, `add`, `info`, `check_circle`, `schedule`, `cancel`, `edit`, `fact_check`, `timeline`, `group`, `menu_book`, `close`, `arrow_back`). Никаких эмодзи и символов вроде «✎ ✕ ⓘ» в интерфейсе.

## 3. Сетка, отступы, формы
- **Единый контейнер на всех страницах:** `--container: 1040px`, боковые поля `--gutter: 24px` (на телефоне 16px). Top app bar, вкладки, контент, таймлайн на главной — по одной левой линии. Это главный ответ на претензию «текст прыгает по левому краю».
- Отступы только из ряда 4/8/12/16/24/32/48. Между карточками 16; между секциями 32; внутри карточек 16.
- Радиусы M3: `--r-xs:4px` (поля), `--r-s:8px` (чипы), `--r-m:12px` (карточки), `--r-l:16px` (FAB, нижний лист), `--r-xl:28px` (диалоги), `999px` (кнопки, поиск, аватары).
- Тени почти не используем: иерархию задают tonal-поверхности (`--surface-low/mid/high`). Тень только у FAB и у поднятой карточки при hover (уровень 1–2).

## 4. Компоненты (что чем является)
- **Top app bar** — одна полоса `.appbar` высотой 52px, sticky, фон `--surface`, нижняя граница 1px `--outline-variant`, заголовка «Татьяна Ивановна Хитрова» нет. Слева — вкладки «Линия жизни · Люди · Наследие» (`label-large`, зазор 24px, активная — `--on-surface` с индикатором 2px `--primary` по нижнему краю шапки, неактивная — `--on-surface-variant`). Справа, слева направо: кнопка «Добавить» (`.btn.tonal`, иконка `add`, высота 36px), иконка модерации с бейджем-счётчиком (только модератору), блок пользователя (аватар-инициал 32px + полное имя `label-large` без обрезки + стрелка `expand_more`, клик по имени/аватару — своя карточка, клик по стрелке — меню «Моя карточка / Модерация / Выйти»; гость — text-кнопка «Войти»). Поиска в шапке нет. На телефоне (< 600px) шапка та же 52px без вкладок — их заменяет **navigation bar** внизу экрана (3 пункта с иконками `timeline / group / menu_book`, активный — `--secondary-container` пилюля); справа в шапке — «Добавить» как `.iconbtn` и аватар без имени. Бургера нет.
- **FAB убран полностью.** Кнопка «Добавить» живёт только в шапке (см. выше); клиренс контента под FAB (96px) не нужен, только отступ под мобильный navigation bar.
- **Кнопки:** filled (главное действие диалога: «Отправить», «Применить»), tonal (второстепенное: «Предложить правку»), outlined («Отмена»), text (ссылки-действия). Высота 40, радиус 999, `label-large`, иконка 18px слева, если есть. Названия — глаголами.
- **Chips (filter):** высота 32, радиус 8, `--outline` рамка; активный — `--secondary-container` + иконка `check`.
- **Поиск:** search bar 56px, радиус 28, `--surface-high`, иконка `search`.
- **Карточки** (люди, материалы, события в списках): `--surface-low`, радиус 12, padding 16, **одинаковая высота в сетке** (люди 172px, 3 колонки на десктопе / 2 до 900px / 1 до 600px). Имя в одну строку с многоточием, описание — `-webkit-line-clamp: 2`. **Метаданные (кто добавил, статус, ⓘ) — в полоске, выезжающей снизу по hover / focus-within**, в покое не видны. Клик по карточке — переход; клик по ⓘ — поповер истории, без перехода.
- **Поля:** outlined text field 56px, радиус 4, плавающий label (`label-medium`, `--primary` при фокусе), supporting text под полем; ошибка — рамка и текст `--error`. Обязательные без звёздочки; необязательные помечены в supporting text.
- **Диалоги:** basic dialog, радиус 28, `--surface-high`, max-width 560 (единое добавление — 720), заголовок `headline-small`, кнопки справа внизу (text/filled). На телефоне < 600px — **full-screen dialog**: app bar с `close` слева, заголовок, filled-кнопка действия справа в баре.
- **Snackbar** вместо тостов: `--inverse-surface` / `--inverse-on-surface`, внизу по центру, 4 с.
- **Поповер метаданных:** menu-подобная карточка `--surface-high`, радиус 12, тень уровня 2, позиция по `getBoundingClientRect()` кнопки; список истории — M3 list items (иконка + две строки).
- **Бейджи статусов:** высота 24, радиус 6, `label-medium`, иконка 16px, цвета из п.1.
- **TimelineJS на главной:** стандартный вид библиотеки, переопределяется только `font-family`.

## 5. Доступность и поведение
- Область нажатия ≥ 48×48 (M3), иконочные кнопки 48px круг со state layer.
- `:focus-visible` — 2px `--primary`, offset 2. Escape закрывает диалоги, меню, поповеры.
- `prefers-reduced-motion: reduce` — отключить transitions.
- Контраст текста ≥ 4.5:1 (все пары «on-X / X» из п.1 это дают; не изобретать свои).
- 375px: без горизонтального скролла, нижний отступ контента под navigation bar.

## 6. Чек-лист перед коммитом
1. [ ] Ни одного hex-цвета и ни одного `font-family` вне `:root` в `style.css`.
2. [ ] Ни одного `font-size` в px вне шкалы `--t-*`; ничего меньше 12px.
3. [ ] Все страницы используют один контейнер 1040/24; левая линия совпадает на всех.
4. [ ] Иконки — Material Symbols, эмодзи/символов в UI нет.
5. [ ] Карточки в сетке одной высоты; длинный текст обрезан, а не растягивает карточку.
6. [ ] Метаданные скрыты в покое, видны по hover/focus; ⓘ работает без перехода по карточке.
7. [ ] Кнопки: filled/tonal/outlined/text по ролям, названы глаголами.
8. [ ] Диалоги на 375px — полноэкранные, действие в верхнем баре.
9. [ ] Фокус виден, Escape работает, reduced-motion учтён.
10. [ ] Проверено на 1280, 375 и планшете (768×1024 и 1024×768): нет горизонтального скролла, сетки и диалоги не ломаются между брейкпоинтами 600 и 1040.
