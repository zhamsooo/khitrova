# Дизайн-правила интерфейса (Material Design 3 адаптация)

Документ фиксирует правила оформления и поведения интерфейса сайта памяти Т.И. Хитровой. Все новые компоненты и доработки (вики-функционал v2, модалки, формы, модерация) обязаны строго следовать этим правилам.

## 1. Шкала отступов (Spacing)
Использовать только фиксированную 8-точечную сетку с половинным шагом:
- **4px** — микроотступы: зазоры внутри бейджей, тегов, отступ иконки от текста.
- **8px** — компактный зазор: промежутки между чипами, кнопками в группе, полями в строке.
- **12px** — стандартный внутренний отступ: padding инпутов, компактных карточек.
- **16px** — базовый шаг: padding стандартных карточек, межблочные отступы в формах.
- **24px** — секционный отступ: padding десктопных модалок, отступы между группами полей.
- **32px** — крупный отступ: поля страниц, разделение смысловых блоков.

## 2. Типографика (Typography)
**Решение владельца 2026-09-14 (вариант B из сравнения):** три роли шрифтов и шкала, поднятая на шаг — аудитория сайта 50–70 лет, прежние 12–14px были мелкими. Все значения задаются переменными в `:root` в `style.css`, в компонентах используются только переменные, не голые px.
- **Шрифты (переменные):**
  - `--font-head: "Cormorant Garamond", "PT Serif", Georgia, serif;` — заголовки страниц и секций, имена людей на карточках, заголовки статей. Weight 600 (700 только для H1). Подключение с Google Fonts на всех страницах: `family=Cormorant+Garamond:ital,wght@0,500;0,600;0,700;1,500`.
  - `--font-body: "PT Serif", Georgia, "Times New Roman", serif;` — основной текст, воспоминания, статьи, описания.
  - `--font-ui: "PT Sans Narrow", -apple-system, "Segoe UI", sans-serif;` — кнопки, чипы, меню, подписи полей, бейджи, мета, хлебные крошки.
- **Шкала (переменные `--fs-*`, десктоп / телефон < 600px):**
  - `--fs-h1`: 46px / 34px, `--font-head`, weight 700, line-height 1.1, `text-wrap: balance`.
  - `--fs-h2`: 25px / 22px, `--font-head`, weight 600, line-height 1.2 (секции, заголовки модалок).
  - `--fs-h3`: 23px / 20px, `--font-head`, weight 600, line-height 1.2 (имена на карточках, заголовки карточек).
  - `--fs-body`: 17px / 16px, `--font-body`, line-height 1.6; в тексте статей 18px / 17px, line-height 1.65. Ширина колонки текста не больше 65–70 знаков (`max-width: 68ch`).
  - `--fs-ui`: 15px, `--font-ui` — кнопки, чипы, поля ввода, пункты меню.
  - `--fs-meta`: 13px, `--font-ui` — подписи полей, мета «кто добавил», подсказки. **Это нижняя граница текста на сайте.**
  - `--fs-badge`: 12px, `--font-ui`, weight 700, uppercase, letter-spacing .06em — только бейджи статусов.
- **TimelineJS на главной** должен использовать те же шрифты: переопределить в `style.css` `.tl-timeline h1, .tl-timeline h2, .tl-timeline h3 { font-family: var(--font-head) }`, `.tl-timeline .tl-text p { font-family: var(--font-body); font-size: var(--fs-body) }`, `.tl-timenav` — `--font-ui`. Иначе главная спорит с остальным сайтом.
- Меньше 13px текст не бывает. Новых кеглей вне шкалы не заводить.

## 3. Цвета и роли (Color Roles)
Брать строго из `:root` `style.css` без добавления сторонних оттенков:
- **Фон страницы**: `#ffffff` — основной чистый фон.
- **Поверхность (Surface / Paper)**: `var(--paper)` (`#fafaf8`) — фон инпутов, карточек-вех, подложек. Карточки в каталогах — `#ffffff`.
- **Основной текст (Ink)**: `var(--ink)` (`#22252a`) — максимальная читаемость.
- **Вторичный текст (Muted)**: `var(--muted)` (`#878d96`) — подписи, хинты, плейсхолдеры.
- **Границы и линии (Line)**: `var(--line)` (`#e4e2dc`) — рамки блоков, инпутов, разделители.
- **Акцент (Accent)**: `var(--accent)` (`#8a6a3a`, тёплая бронза) — ссылки, бейджи годов, авторские акценты.
- **Предупреждение / На проверке**: `var(--warn)` (`#a4641f`) — фон `rgba(164,100,31,.08)`.
- **Подтверждено**: `var(--confirmed)` (`#33547a`, приглушённый синий) — фон `rgba(51,84,122,.08)`, статус одобрения, работы Т.И.
- **Ошибка / Отклонено**: `#b0413e` — фон `rgba(176,65,62,.08)`, сообщения валидации, статус отказа.

## 4. Кнопки (Buttons)
Текст кнопки всегда выражен **глаголом** («Сохранить», «Отправить», «Закрыть»).
- **Primary (главная)**: фон `var(--ink)`, текст `#fff`, border: none, border-radius: 20px (pill) или 8px (в формах).
- **Secondary (контурная)**: фон `#fff`, border: `1px solid var(--line)`, текст `var(--ink)`, border-radius: 14px/8px.
- **Text / Linklike**: background: none, border: none, текст `var(--muted)` с подчеркиванием, hover: `var(--ink)`.
- **Состояния**:
  - `hover`: primary — opacity: .9; secondary — border-color: `var(--ink)`; text — color: `var(--ink)`.
  - `active`: transform: scale(.98) или более глубокий фон.
  - `disabled`: opacity: .45, cursor: not-allowed, pointer-events: none.
  - `loading`: disabled, текст меняется на «Сохранение…», спиннер, блокировка повторных нажатий.

## 5. Поля форм (Form Fields)
- **Label**: всегда строго **сверху** поля (`display: block; font-size: 11.5–12px; color: var(--muted); margin: 10px 0 4px; font-weight: 600`).
- **Обязательность**: обязательные поля без суффикса; необязательные явно помечаются: `(необязательно)`.
- **Инпуты / Select / Textarea**: background: `var(--paper)`, border: `1px solid var(--line)`, color: `var(--ink)`, border-radius: 8px, padding: 8px 10px, font-size: 13px, font-family: inherit.
- **Фокус**: border-color: `var(--ink)`, background: `#fff`, outline: none.
- **Ошибки**: текст ошибки строго **под полем** (`.err { color: #b0413e; font-size: 11.5–12px; margin-top: 4px; }`), у поля `border-color: #b0413e`.

## 6. Модальные окна и мобильные листы (Modal & Bottom Sheet)
- **Десктоп (>= 600px)**:
  - Центрированное окно поверх `.overlay` (`background: rgba(20,20,24,.45); backdrop-filter: blur(2px)`).
  - Ширина: 340–420px (простые формы), max-width 720px (составные модалки), border-radius: 14px.
  - Ограничение высоты `max-height: 88vh`, скролл внутри `.modal-body`. Кнопка закрытия `×` справа вверху.
- **Мобильный (< 600px)**:
  - Полноэкранный нижний лист (bottom sheet): `width: 100%; border-radius: 14px 14px 0 0; max-height: 94vh; margin-top: auto`.
  - Кнопка «Закрыть» сверху, скроллируемый контент (`overflow-y: auto; flex: 1`).
  - Primary-кнопка прижата к нижнему краю экрана (`sticky bottom` или в футере).

## 7. Чипы-фильтры (Chips)
- Контейнер: горизонтальный скролл или flex-wrap, зазор 8–10px.
- Внешний вид: pill-форма (border-radius: 14px), padding: 5px 13px, font-size: 12px, border: `1px solid var(--line)`, color: `var(--muted)`.
- Hover: border-color: `var(--ink)`, color: `var(--ink)`.
- Active (выбран): background: `var(--ink)`, color: `#fff`, border-color: `var(--ink)`.

## 8. Бейджи статусов (Status Badges)
- Типографика: `--font-head`, font-weight: 700, font-size: 10–10.5px, letter-spacing: .05em, text-transform: uppercase, padding: 2px 7px, border-radius: 6px.
- `confirmed` / Опубликовано: цвет `var(--confirmed)`, фон `rgba(51,84,122,.08)`.
- `pending` / `unconfirmed` / На проверке: цвет `var(--warn)`, фон `rgba(164,100,31,.08)`.
- `rejected` / Отклонено: цвет `#b0413e`, фон `rgba(176,65,62,.08)`.
- `draft` / Черновик: цвет `var(--muted)`, фон `#eeeeee`.

## 9. Тултипы и поповеры (Tooltip & Popover)
- Плавающий слой: `position: fixed` или `absolute`, z-index: 60+, background: `#fff`, border: `1px solid var(--line)`, border-radius: 10px, box-shadow: `0 10px 30px rgba(0,0,0,.12)`, padding: 12px 14px.
- Закрытие: клик снаружи (backdrop / outside click), клавиша `Escape`, увод курсора с задержкой 250мс при ховере.

## 10. Доступность (A11y) и тач-область
- **Мин. область нажатия (Touch target)**: не менее **44×44px** для всех интерактивных элементов (иконки, чипы, кнопки закрытия, стрелки). При необходимости использовать компенсирующий padding или псевдоэлементы `::before`.
- **Клавиатурный фокус**: не отключать видимый фокус! Стилизовать `:focus-visible { outline: 2px solid var(--ink); outline-offset: 2px; }`.
- Поддержка навигации клавишами Tab / Shift+Tab, закрытие оверлеев по `Escape`.

## 11. Чек-лист «перед коммитом проверь»
1. [ ] Цвета и шрифты взяты только из существующих переменных (`--font-body`, `--font-head`, `--ink`, `--paper`, `--muted`, `--line`, `--accent`, `--confirmed`, `--warn`, ошибка `#b0413e`).
2. [ ] Отступы соответствуют шкале: 4, 8, 12, 16, 24 или 32px.
3. [ ] Типографика только через переменные `--font-head/--font-body/--font-ui` и `--fs-*`; ни одного текста меньше 13px; Cormorant Garamond подключён на странице.
4. [ ] Кнопки названы глаголами («Сохранить», «Отправить»), обращение к пользователю на «вы».
5. [ ] Поля формы снабжены label сверху, обязательные/необязательные поля явно обозначены.
6. [ ] Сообщения валидации выводятся строго под проблемными полями, поле подсвечено ошибкой.
7. [ ] Проверено на ширине 375px (iPhone 12 mini): нет горизонтальной прокрутки, кнопка действия в модалке видна.
8. [ ] Область касания интерактивных элементов на мобильных составляет минимум 44×44px.
9. [ ] Фокус с клавиатуры виден (`:focus-visible`), диалоги и выпадашки закрываются по `Escape`.
10. [ ] Кнопки блокируются от повторных нажатий при сохранении (loading state), никаких секретов и npm-зависимостей не добавлено.
